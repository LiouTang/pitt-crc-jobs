# pitt-crc-jobs

Skill for writing, submitting, and monitoring Slurm jobs on the [University of Pittsburgh CRC computing cluster](https://crc.pitt.edu/).

## Installation

**Codex**:

```sh
git clone https://github.com/LiouTang/pitt-crc-jobs.git .agents/skills/pitt-crc-jobs
```

**Claude Code**:

```sh
git clone https://github.com/LiouTang/pitt-crc-jobs.git .claude/skills/pitt-crc-jobs
```
